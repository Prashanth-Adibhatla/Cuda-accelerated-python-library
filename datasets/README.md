# Datasets Directory

This folder holds large benchmark datasets used by `benchmark_and_comparisons.ipynb`:
* **HIGGS Dataset:** (`HIGGS.csv.gz` / `HIGGS.csv`)
* **YearPredictionMSD:** (`YearPredictionMSD.txt`)
* **SIFT-128 Vectors:** (`sift.npy`)
* **2D Raster Matrix:** (`raster.npy`)

### Automated Setup
To download and set up all datasets automatically, run:
```powershell
python download_datasets.py
```
*(Large binary files are excluded from Git to comply with GitHub's file size limits.)*
